# Basic C++ Concepts

This folder contains fundamental C++ programming concepts and syntax examples.

## Files Overview

- **hello.cpp** - Basic "Hello World" program
- **boolean.cpp** - Boolean data type and operations
- **char.cpp** - Character data type and operations
- **conditions.cpp** - If-else statements and conditional logic
- **operators.cpp** - Arithmetic, logical, and comparison operators
- **math.cpp** - Mathematical operations and functions
- **string.cpp** - String manipulation and operations
- **while.cpp** - While and do-while loops
- **switch.cpp** - Switch-case statements
- **ternary.cpp** - Ternary operator usage
- **shiftOperator.cpp** - Bitwise shift operations
- **UserInput.cpp** - Reading user input from console

## Compilation

To compile any file in this directory:
```bash
g++ -std=c++17 filename.cpp -o filename
./filename
```

Or use the Makefile from the root directory:
```bash
make basics
```

## Learning Path

1. Start with `hello.cpp` for basic program structure
2. Learn data types: `boolean.cpp`, `char.cpp`
3. Understand operators: `operators.cpp`, `math.cpp`
4. Control flow: `conditions.cpp`, `while.cpp`, `switch.cpp`
5. Advanced concepts: `ternary.cpp`, `shiftOperator.cpp`
6. User interaction: `UserInput.cpp`
